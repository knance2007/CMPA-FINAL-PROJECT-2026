# CMPA-FINAL-PROJECT-2026
### The NANCE LAW FIRM
This project is a two‑page website for a fictional law firm I created for my CMPA coursework. It includes a home page (index.html) and an about page (about.html), both featuring legal images and a professional headshot to support the overall theme of the site. The project includes a scope statement, a project plan, and a retrospective that walk through my thought process and keep the work aligned with its original goals.

The purpose of this project was to build a clean, organized site that is user friendly using semantic HTML and CSS while practicing proper file structure and risk management. It also serves as an early piece in my professional portfolio as I continue developing my skills for future coursework and career opportunities.
